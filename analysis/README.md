# 데이터 분석 노트북 정리

이 폴더는 말하기형 인지검사/인지훈련 서비스의 음성 답변 분석 기능을 구현하기 전에 진행한 데이터 분석 및 실험용 Colab 노트북을 정리한 공간입니다.

노트북들은 STT 모델 적용 가능성 검토, STT 텍스트 전처리, 반응 시간 측정, 반복어 비율 계산, 평균 문장 길이 산출, 문항 데이터 정리 및 DB 연동 테스트를 목적으로 작성되었습니다.

## 노트북 목록

| 파일명                          | 내용                                                           |
| ---------------------------- | ------------------------------------------------------------ |
| `STT_모델_사용하기.ipynb`          | Hugging Face 기반 Whisper 계열 STT 모델을 불러오고 음성 파일을 텍스트로 변환하는 테스트 |
| `노인_TTS_+_STT_테스트.ipynb`     | TTS로 생성한 노인 음성 샘플을 STT로 변환하여 인식 결과를 확인한 테스트                  |
| `데이터_전처리.ipynb`              | AI HUB 고령층 음성 데이터 및 라벨링 데이터 전처리 실험                           |
| `STT_텍스트_전처리_코드_작성.ipynb` | STT 변환 결과에서 잡음 표기, 라벨성 표기, 불필요한 공백 등을 제거하는 전처리 코드 작성         |
| `반응_시간_측정하기.ipynb`        | 음성 파일에서 첫 발화가 감지되는 시점을 기준으로 반응 시간을 계산하는 실험                   |
| `반복어_비율_채점하기.ipynb`       | STT 텍스트에서 연속 반복 어절을 탐지하고 반복어 비율 및 점수를 계산하는 실험                |
| `평균_문장_길이_채점하기.ipynb`     | STT 텍스트에서 채움 표현을 제외하고 평균 문장 길이 지표를 산출하는 실험                   |
| `채점_테스트.ipynb`            | 반응 시간, 반복어 비율, 평균 문장 길이, 화행 적절성 점수 등 주요 분석 항목의 통합 테스트        |
| `문항_분할하기.ipynb`              | 인지검사/인지훈련 문항 데이터를 유형별로 정리하고 분할하는 작업                          |
| `문항_데이터_DB_연동.ipynb`         | 문항 데이터를 DB에 저장하거나 연동하기 위한 테스트                                |

## 분석 항목

본 프로젝트에서 음성 답변 분석에 활용한 주요 항목은 다음과 같습니다.

| 분석 항목       | 설명                                     |
| ----------- | -------------------------------------- |
| STT 변환      | 수급자의 음성 답변을 텍스트로 변환                    |
| STT 텍스트 전처리 | 잡음 표기, 라벨성 표기, 불필요한 공백 등을 제거           |
| 반응 시간       | 음성 파일에서 첫 발화가 감지되는 시점까지의 시간            |
| 반복어 비율      | 같은 어절이 바로 연속해서 반복되는 비율                 |
| 평균 문장 길이    | 공백, 문장부호, 명확한 채움 표현을 제외한 답변 전체 의미 글자 수 |
| 화행 적절성 점수   | 문항 유형과 답변 내용의 적절성을 LLM 기반으로 평가         |

## 참고

이 폴더의 노트북은 분석 로직을 설계하고 검증하기 위한 실험용 파일입니다.
실제 백엔드 연동에는 노트북 코드를 정리한 Python 분석 파이프라인 파일을 사용합니다.

API Key, 개인 경로, 대용량 음성 데이터 등은 GitHub에 포함하지 않습니다.
